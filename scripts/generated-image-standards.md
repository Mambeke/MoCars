# Generated vehicle image standards

Every generated vehicle listing uses four separate, photorealistic horizontal gallery images:

1. Front three-quarter exterior
2. Rear three-quarter exterior
3. Dashboard and infotainment-screen close-up
4. Rear-seat view

Requirements for every future image:

- Exterior views must carry a physically realistic white MoCars dealership plate, using the supplied navy/red MoCars branding and correct perspective, reflections and shadows.
- Every cabin must be right-hand drive. The steering wheel and instrument cluster belong on the right, and badges, controls and screens must remain correctly oriented rather than mirrored.
- Front, rear and cabin images must represent the same model, generation, paint colour, wheels, trim and upholstery.
- Photographs must look realistic, use natural dealership lighting and close marketplace framing, and contain no people, watermarks or unrelated text.
- Generated images are illustrative. Listing descriptions must tell customers to confirm the actual vehicle, model year, colour, specifications, availability and condition with MoCars.
- Do not publish a listing until all four images pass visual review.
